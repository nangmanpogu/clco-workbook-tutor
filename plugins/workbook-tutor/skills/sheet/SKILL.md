학습 도우미의 /학습지 다. Claude 앱의 내장 브라우저는 세션마다 따로 열리고 작업 폴더마다 로그인이 따로다. 그래서 새 세션을 열면 학습지가 닫힌다. 이 명령은 학습지를 하던 자리로, 로그인한 채로 다시 연다.

## 1. 열 주소를 받는다

Bash 로 `workbook-tutor sheet` 를 부른다. 학습자의 지금 폴더에서 그대로 부른다. `cd` 를 앞에 붙이지 않는다.

| 줄      | 뜻                                                                           |
| ------- | ---------------------------------------------------------------------------- |
| `OPEN`  | 열 주소. 1분짜리 로그인 코드가 들어 있을 수 있다                             |
| `LOGIN` | `yes` 면 로그인한 채로 열린다. `no` 면 학습자가 구글로 한 번 로그인해야 한다 |
| `UNIT`  | 연 장. 비어 있으면 목차다                                                    |

## 2. 내장 브라우저로 연다

- 내장 브라우저 도구는 이름에 `Claude_Browser` 가 든 도구다. 목록에 없으면 ToolSearch 로 `Claude_Browser` 를 찾아 한 번에 불러온다.
- `preview_start` 에 `OPEN` 의 주소를 `url` 로 주어 새 탭으로 연다. 로그인 코드는 1분 안에 한 번만 쓰이므로 받자마자 연다.
- 연 뒤 `tabs_context` 를 부른다. 끝 줄이 브라우저 칸이 숨었다거나 열리지 않았다고 하면 3의 문장 뒤에 「오른쪽 위의 지구본 버튼을 눌러요.」를 붙인다.

## 3. 학습자에게 알린다

해요체로 한 줄만 쓴다.

- `LOGIN` 이 `yes`: 「옆에 학습지를 열었어요.」
- `LOGIN` 이 `no`: 「옆에 학습지를 열었어요. 로그인 화면이 나오면 Google로 계속하기를 눌러요.」

내장 브라우저 도구가 없으면(터미널의 Claude Code) 주소를 열지 않고 「학습지는 브라우저에서 console.clcoach.nangmanpg.com 으로 열어요.」라고만 알린다.

## 하지 않는 것

- `OPEN` 의 주소를 대화에 적지 않는다. 로그인 코드가 들어 있어 학습자의 계정으로 들어가는 열쇠다.
- 학습지 페이지를 읽거나 누르지 않는다. 여는 것까지만 한다. 학습지를 따라 하는 것은 학습자다.
