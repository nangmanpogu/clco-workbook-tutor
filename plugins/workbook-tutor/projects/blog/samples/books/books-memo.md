# 읽고 본 것

다 읽은 책, 다 본 영화만 짧게.

## 소설 「아무렇지 않은 얼굴」

- 이번 주에 다 읽음. 도서관에서 빌림
- 감정을 잘 못 느끼는 주인공이 친구 하나를 만나면서 조금씩 달라지는 이야기
- 앞부분은 좀 느렸는데 중간부터는 금방 읽힘
- 마지막 장면에서 조금 울었음. 지하철 안이었는데
- 밑줄 친 문장: "모르는 건 모르는 채로 옆에 두면 된다."
- 사진: 책상 위 책, 책갈피 끼운 마지막 장, 창가 자리

## 영화 「아홉 시 버스」

- 토요일 아침 첫 회. 관객 열 명쯤
- 대사가 거의 없고 버스 창밖 풍경이 길게 나옴
- 졸릴 줄 알았는데 끝까지 봄
- 사진: 영화표

## 읽을 것

- 같은 작가가 처음 쓴 소설
- 친구가 빌려준 여행 에세이
